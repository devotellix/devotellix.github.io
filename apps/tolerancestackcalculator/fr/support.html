Aide pour vos calculs

Indiquez la version de l’application, la version d’iOS, l’outil, les unités et les étapes permettant de reproduire le problème. Remplacez les valeurs confidentielles par un petit exemple.

Comment obtenir un premier résultat ?

Choisissez un calculateur, remplacez les données d’exemple par vos valeurs, puis touchez Calculer. Vérifiez les unités et ouvrez Méthode pour consulter les hypothèses et les sources.

Pourquoi le résultat a-t-il disparu ?

Une modification invalide l’ancien résultat. Corrigez les champs, puis touchez à nouveau Calculer. L’enregistrement devient disponible après un calcul valide.

Comment conserver un cas ?

Touchez Enregistrer, choisissez un projet existant ou nommez un nouveau projet, puis nommez le cas. Rouvrez-le dans Projets pour modifier ses données. Enregistrez avant de quitter pour conserver votre travail.

Comment exporter ou supprimer ?

Ouvrez un projet, préparez son PDF, puis utilisez le partage système. La suppression d’un projet ou d’un cas demande confirmation. Elle ne supprime pas les copies déjà partagées.

Quelles sont les limites ?

Le RSS repose sur les hypothèses d’indépendance et de distribution indiquées. Le calcul thermique utilise votre coefficient sur la plage choisie. Le perçage avant taraudage est une estimation pour taraudage par coupe. Le jeu alésage/arbre utilise vos limites explicites, sans recherche de désignation ISO.

Une connexion est-elle nécessaire ?

Non pour les calculs et les méthodes intégrées. Oui pour ouvrir les pages externes de sources, de confidentialité et d’assistance. Aucun compte ni abonnement n’est nécessaire.
