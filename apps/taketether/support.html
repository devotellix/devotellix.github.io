Get your takes ready

Use two separate dry vocal recordings of the same phrase. Export mono files from your recording app at the same sample rate. Start with a short phrase, then choose the guide first and the double second.

Mono WAV, AIFF or M4A · 0.5–30 seconds · 44.1 or 48 kHz · up to 20 MB per file

If a file or result does not work

For best results, use isolated vocals without reverb, with the same words and similar phrasing. If alignment sounds unnatural, reduce the strength or use a shorter phrase. Always compare the original and aligned takes before exporting. Include your app version and file format when contacting support; do not send private recordings.
